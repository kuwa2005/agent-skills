# access2spec

MS Access（.mdb/.mde/.accdb）資産を静的解析し、設計書13種（提案書・要件定義書・外部設計書・内部設計書・プログラム設計書・テスト仕様書・業務フロー・画面設計書・マクロ仕様・VBA仕様・機能一覧・操作マニュアル・説明書）と一覧ページ `index.md` を Markdown で生成するスキル。

- クエリ SQL は MSysQueries ツリーから再構築（sample.mdb 実測 780/780 復元）
- フォーム/レポート/マクロ/リレーション/VBA 有無を抽出し、業務フロー・画面設計・機能一覧まで自動生成
- 抽出の限界（マクロのアクション定義・フォームの完全なコントロール定義等）は「（要Access確認・推定）」と明記
- Excel マクロ資産は [xlsm2spec](./../xlsm2spec/SKILL.md) と連携

→ 詳細は [SKILL.md](./SKILL.md)
